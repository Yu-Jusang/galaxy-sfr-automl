# 은하 SFR 예측: AutoML 총동원 실험 최종 보고서

작성 2026-11-03 · 저장소 https://github.com/Yu-Jusang/galaxy-sfr-automl (선택 규칙 커밋 c99f90d)

## 요약

원래 최종 모델 R0(무튜닝 LightGBM + Tweedie p = 1.3, 변수 25개, CV RMSE 7.401)를 이기려고, 네 기기(A·B·C·D)에서 후보 139개를 학습 80% 안의 같은 5-fold CV로 비교했다. 후보는 단일 모델 91개, 튜닝 20개, 변수 선택 8개, AutoGluon 11개, 앙상블 9개다.

- **최종 모델:** 사전에 정한 1-SE 규칙으로 `AG26_F5C_wmassive`를 골랐다. AutoGluon best_quality이고, 변수는 F5C 47개, 거대 은하(log M\* > 11.5)에는 가중치 2를 줬다. CV RMSE는 7.274로 R0 대비 −0.128(SE 0.089, 5개 fold 중 4개 개선)이다.
- **test 결과:** test 20%(41,688개)는 선택이 끝난 뒤 한 번만 평가했다. 최종 모델의 RMSE는 7.841, MAE 1.022, R² 0.584다. R0의 test RMSE는 7.619로, 차이 +0.222의 95% bootstrap 구간 [−0.416, +0.916]이 0을 포함한다. 즉 CV에서 본 개선을 test로는 확인하지 못했다.
- **test에서 진 이유:** 차이는 거의 전부 SFR 수백 대 거대 은하 세 개에서 나왔다. 이 세 개를 빼면 최종 모델 5.889, R0 6.019로 순서가 뒤집힌다.
- **선택 편향:** CV 1위를 고르는 절차까지 중첩한 CV는 7.338, Tibshirani 보정값은 7.547이다. 따라서 CV 7.27은 낙관적인 값이다.

## 1. 과제와 원칙

- **데이터:** SNU DataHub dataset 42(CROCODILE 시뮬레이션, CC BY 4.0)의 은하 208,437개.
  - 목표는 순간 별 생성률 `sfr_linear`이다.
  - 학습 분할의 8.66%가 SFR = 0이고, 최댓값은 2,145다.
- **분할:** 대회 양식의 고정 80/20 분할을 썼다(train_test_split, test_size 0.2, random_state 42, SFR > 0 여부로 층화).
  - 학습 166,749개, test 41,688개다.
  - 양식은 20%를 X_val이라 부르지만 이 보고서에서는 test라고 부른다.
- **검증:** 학습 80% 안에서 11층 층화 5-fold CV를 썼다.
  - 모든 후보가 같은 fold와 같은 행을 쓴다.
  - 검증 결과, 139개 OOF 파일의 행·fold·정답이 모두 일치했다.
- **원칙:** 튜닝, 변수 선택, 앙상블 가중치, 최종 선택은 모두 CV로만 했다.
  - test는 마지막에 한 번만 열었고, 그 결과로는 아무것도 바꾸지 않았다.
  - 원본 CSV와 행 단위 예측은 공개하지 않는다.

## 2. 실험 설계

### 2.1 기기 분담

| 기기 | 내용 | 결과 수 |
|---|---|---|
| A (조원 Mac) | 단일 모델, 선형·커널, 변수 선택, AutoGluon 2회 | 51 |
| B (이 노트북 → 조원 Mac) | 딥러닝·TabPFN·xRFM, TabM·RealMLP 튜닝 | 20 |
| C (조원) | 트리 nested Optuna 튜닝, AutoGluon 1회 | 4 |
| D (이 노트북) | AutoGluon 변수·목표 축 7회 | 7 |
| 이전 실험 | 원 프로젝트와 1차 sweep의 단일 모델 | 57 |

B는 처음에 이 노트북(CPU)에서 돌렸다. 그런데 결측치 오류와 TabM의 시간 상한 무시 때문에 상당수가 실패했다. 실패한 모델은 조원 Mac(Apple MPS + CPU)에서 다시 돌려 20개를 모두 끝냈다. 이 노트북에서 이미 끝난 F5 모델 3개는 원칙대로 기존 결과를 남겼다.

### 2.2 변수 세트

- **F5 (25):** 원 프로젝트의 최종 세트. 카탈로그 질량·과밀도 7개, 물리 파생 9개, 주기 경계 이웃 환경 9개다.
- **F5C (47):** F5에 문헌 그룹 L1·L3·L4·L7을 더한 세트. 실행 전에 미리 정했다.
  - L1: 최대 헤일로 질량과 strip
  - L3: BH 성장
  - L4: 위상공간
  - L7: 결합 구조
- **F5LS (89):** F5에 문헌 변수 전체와 조원 이웃 변수 27개를 더한 세트.
- **F5X (153):** 우리가 만든 변수 전부.
- **FULL:** F5X에 조원 2의 변수 모듈을 더한 세트.
- **T2CORE:** 조원 2의 핵심 세트.

### 2.3 모델군

- **트리:** LightGBM, XGBoost, CatBoost, HGB, ExtraTrees, RandomForest. 손실은 Tweedie, Poisson, 제곱오차, log 목표를 썼다.
- **선형·커널:** ridge, lasso, Tweedie GLM, kernel ridge, kNN.
- **신경망:** MLP(Tweedie), TabM, RealMLP.
- **기타:** xRFM, TabPFN v2.
- **AutoGluon:** best_quality, 1.5시간 설정이다. 축은 두 가지다.
  - 변수 축: F5, F5C, F5LS, F5X, FULL, T2CORE
  - 목표·가중 축: Tweedie, log, sqrt, 거대 은하 가중, extreme

## 3. 결측치 처리

결측은 변수 정의상 구조적으로 생긴다.

- **L4 위상공간 변수(`ur`, `ut`, `E`, `j` 등):** 더 무거운 숙주가 없는 은하는 정의되지 않는다. 507개이고, 대부분 헤일로 질량이 10^13 이상이다.
- **L6 조석 변수(근거리):** 8 Mpc/h 안에 10·R200 이내 이웃이 없는 은하다. 54,298개다.

모델별 처리 방식은 다음과 같다.

- **트리와 AutoGluon:** 결측을 그대로 받는다. AutoGluon은 내부에서 모델별로 채운다.
- **신경망·커널:** 커밋 310af10에서 학습 fold 중앙값으로 채우고 결측 표시 열(0/1)을 붙이도록 정했다.
- **실제 B 실행:** 조원은 수정 전 코드에 자체 실행 코드를 덧붙여 돌렸다. 학습 fold 중앙값으로 채우기만 했고, 결측 표시 열은 붙이지 않았다. 중앙값은 학습 fold에서만 구했으므로 평가 fold의 정보가 새지는 않았다.

결측 은하에서의 예측도 따로 점검했다. 학습 분할에서 L4 결측은 393개, L6만 결측은 43,437개다.

- L6 결측 은하에서 RealMLP의 RMSE는 3.13–3.19로, 결측을 그대로 받는 트리(3.43–3.44)보다 낮았다.
- 평균 예측은 1.86–2.08로, 실제 평균 1.99와 맞았다.
- L4 결측 은하(거대 은하)에서 RealMLP·TabM은 트리와 비슷했다.
- 이 처리 차이가 결과를 망쳤다는 증거는 찾지 못했다.

## 5. 앙상블

128개 base 모델의 OOF 예측으로 앙상블 9종을 만들었다. 예측이 발산한 Tweedie GLM 2개는 뺐다. 가중치는 CV 안에서 정했다. fold k의 예측은 나머지 네 fold로 정한 가중치로 만들었다(Wolpert 1992). 방법별 근거는 `docs/ensemble_literature.md`에 정리했다.

- 학습한 가중치는 다른 fold로 잘 옮겨 가지 않았다. simplex와 greedy는 AG26 단독보다 0.18 나빴다.
- bagging과 중복 제거를 더하자 greedy가 7.462에서 7.348로 좋아졌다. 그래도 AG26에는 못 미쳤다.

- 위 두 가지는 TabArena(2025)가 경고한 현상과 같은 방향이다. 상위 모델이 대부분 비슷한 AutoGluon 실행이라, 계열 다양성으로 얻는 이득이 작았다.

## 6. 최종 선택

**규칙.** test를 열기 전에 커밋 c99f90d로 정했다. CV 1위가 앙상블이고, 그와 fold별 paired 차이가 1 SE 안인 비앙상블 후보가 있으면, 그중 CV가 가장 낮은 것을 최종으로 한다(Cawley & Talbot 2010).

- 처음 합의한 규칙은 "CV 최저"였다. 위 앙상블 결과를 본 뒤, test 전에 이 규칙으로 바꿨다.
- 비앙상블 후보 사이에서는 더 단순한 모델로 내려가지 않기로 했다.
- "1 SE 안이면 가장 단순한 모델"을 모든 후보에 적용하는 대안도 검토했다. 그랬다면 단일 LightGBM `M67_lgbm_tw13_F5+L7`(CV 7.396)이 최종이 됐을 것이다. 하지만 사전 규칙으로 택하지 않았다.

**적용.** CV 1위는 `ENS_top3`(7.269)였다. AG26과의 차이는 0.005이고, 이긴 fold는 2/5였다. 1 SE 안이므로 최종 모델은 `AG26_F5C_wmassive`다.

**선택 편향 점검** (학습 분할만 사용)

- 1위를 고르는 절차 자체를 중첩 CV로 평가하면 7.338이다(Varma & Simon 2006).
- 최솟값 편향을 Tibshirani & Tibshirani(2009) 방식으로 보정하면 7.547이다.
- CV 1위와 1 SE 안의 후보는 `AG26_F5C_wmassive`, `AG3_F5`, `AG23_F5C_tweedie`, `M67_lgbm_tw13_F5+L7`, `AG25_F5C_sqrt`다.

### 해석

- **test가 구분할 수 있는 폭이 좁다.** 최종 모델과 R0의 test 차이는 +0.222이고, 95% 구간 [−0.416, +0.916]의 폭이 1.3이다. 반면 CV 7.6 이하의 후보 37개는 test 7.30–8.10에 흩어져 있다. 따라서 test 순위(최종 모델은 139개 중 49위)는 후보를 가릴 해상도가 없다. 그래도 CV와 test 순위의 Spearman 상관은 0.859로, 큰 차이는 두 평가가 일관되게 보여 준다.
- **차이는 극소수 거대 은하에서 나온다.** 최종 모델과 R0의 test 제곱오차 차이는 거의 전부 몇몇 은하에서 나온다.
  - 차이가 가장 큰 은하 하나가 전체 차이의 106%를 설명한다.
  - 실제 SFR이 788, 884, 653인 은하를 최종 모델은 279, 152, 86으로, R0는 461, 229, 43으로 예측했다.
  - 이 세 개를 빼면 RMSE는 최종 모델 5.889, R0 6.019다.
  - 원 프로젝트도 OOF 제곱오차의 약 70%가 상위 10개 은하에서 나온다고 보고했다. 같은 구조다.
- **사후 관찰(선택에 쓰지 않음).** F5C 기반 AutoGluon(AG20·23·25·26)와 단일 트리(M80)는 test에서 모두 7.84–8.10에 머물렀다. F5 기반(AG3 7.484, R0 7.619)보다 나쁘다. 그러나 이것은 test를 본 뒤의 관찰이다. 그 원인이 L4 결측 거대 은하의 처리인지, 운인지는 이 자료만으로 가릴 수 없다.

## 8. 한계

- **지표의 꼬리 지배:** 선형 RMSE를 거대 은하 몇 개가 좌우한다. CV fold SD는 약 2.8이고, test 차이의 구간 폭은 1.3이다. 0.1–0.2 수준의 개선은 이 자료에서 검증할 수 없다.
- **선택 편향:** 후보가 139개라 CV 최솟값은 낙관적이다. 중첩 추정은 7.338, 보정 추정은 7.547이다. 또 base 모델의 설계(예: AG26의 가중치)도 CV를 본 뒤 정했다. 이 낙관은 어떤 중첩으로도 지워지지 않는다.
- **규칙 변경:** 최종 선택 규칙은 실행 도중 "CV 최저"에서 1-SE로 바꿨다. test 전이었고 커밋으로 남겼지만, 앙상블의 CV 결과를 본 뒤의 변경이다.
- **B의 처리 차이:** 결측 표시 열이 빠졌다. TabPFN은 10,000개 맥락으로 제한했다. Mac에서 MPS와 CPU를 섞어 계산했다. AG20은 시간 초과로 불리한 조건에서 끝났다.
- **일반화:** 단일 시뮬레이션의 단일 스냅숏이다.
