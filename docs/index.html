01개요

과제
시뮬레이션 은하 208,437개의 질량·성장·환경으로 별 생성률 sfr_linear를 예측하는 회귀. SFR = 0이 8.66%, 최댓값 2,145의 두꺼운 꼬리.
평가
양식 고정 80/20 분할의 검증셋(41,688개) 선형 RMSE. 낮을수록 좋다.
출발점
원래 최종 모델 R0 = 무튜닝 LightGBM, Tweedie p = 1.3, 변수 25개(F5). CV 7.401, 검증 7.619.
이번 목표
단일 모델 총동원 → AutoGluon(전처리 7가지) → 앙상블로 RMSE를 최대한 낮춘다.
선택 원칙
모든 비교는 학습 80% 안의 같은 5-fold CV. 최종 후보 = CV RMSE가 가장 낮은 것. 검증셋은 선택이 끝난 뒤 한 번만 평가한다.
공개 범위
코드·결과 요약·보고서만 올린다. 원본 CSV와 개인정보는 올리지 않는다(데이터: Fukushima & Kim, SNU DataHub dataset 42, CC BY 4.0).

05결과

최종 선택과 검증셋

모든 실험이 끝나면 CV 1위 후보를 고르고 검증셋을 한 번 평가해 여기에 적습니다.

전체 실험 (CV RMSE 순)

CV RMSE = 학습 80% 안 5-fold 평균. Δ = 같은 fold끼리 뺀 차이의 평균(음수면 R0보다 좋음), SE = 그 표준오차. 파란 줄은 R0, 초록 줄은 현재 1위.
